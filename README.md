# Cedric Developer Workspace

Mein persönlicher Lern- und Entwicklungsworkspace zur Vorbereitung und Begleitung meiner Umschulung zum **Fachinformatiker für Anwendungsentwicklung (IHK)**.

## Über mich

Am 17.08.2026 beginne ich meine Umschulung bei bei COMCAVE in Dortmund zum Fachinformatiker für Anwendungsentwicklung.

Bereits vor Beginn meiner Umschulung habe ich mich intensiv mit den Grundlagen der Anwendungsentwicklung beschäftigt. Mir war dabei besonders wichtig zu verstehen, wie Anwendungen grundsätzlich funktionieren und wie die einzelnen Bestandteile zusammenspielen.

Für meinen Einstieg habe ich mich zunächst praktisch mit HTML, CSS und JavaScript beschäftigt und erste eigene Frontend-Projekte umgesetzt. Anschließend habe ich meinen Schwerpunkt auf Backend-Grundlagen und Datenbanken erweitert, um zu verstehen, wie Anwendungen Daten verarbeiten und speichern und wie Datenbankzugriffe sicher umgesetzt werden können.

Während meiner Umschulung möchte ich meine Kenntnisse in der Softwareentwicklung weiter vertiefen und praktische Erfahrung in professionellen Entwicklungsprozessen sammeln. Langfristig interessiert mich besonders der Bereich **IT-Security**, weshalb ich mir ein fundiertes Verständnis für Softwareentwicklung, Datenbanken und sichere Anwendungen aufbauen möchte.

## Projekte

### Lagerverwaltung

Eine mit PHP und MySQL entwickelte Anwendung zur Verwaltung von Lagerartikeln. Artikel können angelegt, angezeigt, gesucht, bearbeitet und gelöscht werden.

**Technologien und Konzepte:**

* HTML
* PHP
* MySQL / SQL
* CRUD (Create, Read, Update, Delete)
* Prepared Statements
* Serverseitige Validierung
* Sichere HTML-Ausgabe mit `htmlspecialchars()`

[Lagerverwaltung ansehen](01_Projekte/011_Lagerverwaltung)
